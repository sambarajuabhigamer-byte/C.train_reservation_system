# 🚂 Train Reservation System - C Project

A simple console-based Train Ticket Booking system made in C language for college project.

### ✨ Features
- 1. VIEW TRAINS - Available trains and fare list
- 2. TICKET BOOKING - Book tickets by train ID
- 3. VIEW BOOKINGS - Check your current booking
- 4. SAVE & EXIT

### 🚆 Trains Available

| 4 | GUNTUR EXPRESS | 100 |
